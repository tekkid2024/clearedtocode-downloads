# ClearedToCode Airline Hub Suite

Virtual Airlines, CTC Aircraft Maintenance, Airport Emergencies and Vantage
cameras in one tablet app for Microsoft Flight Simulator 2024
(Windows 10/11, 64-bit).

- Free 3-hour demo; a serial from <https://clearedtocode.com> unlocks it.
- The installer is per-user and needs no admin rights. Close any running
  Airline Hub before installing. A new version installs over the old one and
  keeps your data.
- The owner's manual ships with the release it was written for (the latest is
  in 1.1.0) and is also inside the app under **Settings > Help**.
- Version 1.0.0 was named *Airline Hub* and also supported MSFS 2020.
