# FlightDeck Bridge

A vPilot plugin that turns a tablet or phone on your Wi-Fi into a VATSIM
message screen: ATC text, private messages, SELCAL alerts, nearby controllers,
ATIS and METAR, sending messages, squawk ident and Mode C. It also adds Hoppie
CPDLC, an MSFS 2024 EFB app and toolbar panel, a radio kneeboard built from
your SimBrief plan, a comms leveler, a Stream Deck plugin and an OBS stream kit.

Pilots install it with a double-click; a pop-out window with a QR code connects
the tablet. Requires Windows and vPilot.

Source code: [tekkid2024/FlightDeckBridge](https://github.com/tekkid2024/FlightDeckBridge) (private).
